    🧪 Ejemplos Prácticos

    Ejemplo 1: Calcular área de una piscina circular

    Problema: Necesitas saber cuántos litros de agua caben en una piscina circular de 3 metros de radio.

    // Calcular área de la piscina
double radio = 3.0; // metros
double area = CalculadoraBuena.calcularAreaCirculo(radio);
System.out.println("Área de la piscina: " + area + " m²");


// Si la profundidad es 1.5 metros
double profundidad = 1.5;
double volumen = area * profundidad;
System.out.println("Volumen: " + volumen + " m³");
System.out.println("Litros: " + (volumen * 1000) + " litros");

    Resultado: Aproximadamente 42,411 litros

    Ejemplo 2: Calcular azulejos para baño

    Problema: ¿Cuántos azulejos de 20×20 cm necesitas para un baño de 2×3 metros?

    // Área del baño
double area = CalculadoraBuena.calcularAreaRectangulo(2.0, 3.0);
System.out.println("Área del baño: " + area + " m²");

// Área de cada azulejo (20cm = 0.2m)
double areAzulejo = CalculadoraBuena.calcularAreaRectangulo(0.2, 0.2);
double numeroAzulejos = area / areAzulejo;
System.out.println("Azulejos necesarios: " + Math.ceil(numeroAzulejos));

    Resultado: 150 azulejos (redondeando hacia arriba)

    Ejemplo 3: Distancia entre ciudades

    Problema: Calcular distancia en línea recta entre Madrid (40.4168, -3.7038) y Barcelona (41.3851, 2.1734).

    Nota: Este ejemplo usa coordenadas simplificadas para demostración.

    // Coordenadas simplificadas (sin conversión de grados)
double distancia = CalculadoraBuena.calcularDistancia(40.4168, -3.7038, 41.3851, 2.1734);
System.out.println("Distancia aproximada: " + distancia + " unidades");
